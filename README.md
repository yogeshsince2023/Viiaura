# Viiaura — Candle Art & Sculptural Studio

> Premium digital catalogue and bespoke enquiry showroom for handcrafted sculptural candles and future craft lifestyle objects.

## Philosophy & Architecture
- **Digital Showroom & Catalogue:** Zero e-commerce cart/checkout friction. Focuses on visual admiration, material tactility, and direct client connection.
- **Conversion Pathways:** Direct 1-tap WhatsApp studio enquiry with pre-filled product details, plus structured custom & bulk gifting enquiry forms.
- **Tech Stack:** Next.js 15 (App Router), React 19, Tailwind CSS v4, Lucide Icons, Framer Motion.

## Getting Started

### Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to explore the showroom.

### Production Build
```bash
npm run build
npm run start
```

## Deployment
Optimized for zero-config deployment on [Vercel](https://vercel.com).
